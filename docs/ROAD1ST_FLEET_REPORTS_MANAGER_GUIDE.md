# ROAD 1ST — Fleet Manager Report Guide
Draft dated 12 October 2026. Review before sharing with customers.

### Reading a report
Sign into the authorised Fleet Portal. Check your company name. Open Reports or Fleet Records, then filter by vehicle, date or category where available. Select View report for an activity timeline or Preview for an authorised image.

### Downloads
- Download original: preserves the uploaded source report.
- Download PDF report: current English-language summary.
- Print / Save as PDF: separately staged optional printable preview in the fleet manager's selected portal language, not yet publicly released or visually verified.

### Evidence
Journey duration and individual driver activity are not the same measurement. GPS speeds and work-time estimates do not replace official tachograph records. A report arriving later on Wi-Fi can have an earlier creation timestamp. Keep originals for formal review.

### Access
Only authorised fleet representatives should access or share driver records. Cross-fleet access, image links and account revocation still require independent negative tests.
